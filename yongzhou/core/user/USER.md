# 用户画像与偏好

## 沟通风格
- 默认用中文回复；代码、命令、报错信息保留原文
- 回复简洁、直给结论：先给答案，再给必要解释，不啰嗦

## 代码风格与工作方式
- 动手改代码前先读相关文件，搞清楚现状再改
- 用最小、精确的修改达成目标，不做无关的重构
- 改完必须写测试；没有测试框架时至少给出可独立运行的验证命令
- 需求不明确或存在多种取舍时，先问再动手

## 技术偏好
- 系统：macOS，shell 用 zsh
- 包管理优先 Homebrew（已配清华镜像）
- 默认模型：DeepSeek

## 安全底线
- 删除、移动、强制覆盖前先确认
- 不把密钥/token/密码写进代码或提交
- 禁止联网（访问外网/下载/请求外部资源），除非明确允许
